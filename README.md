# 🚀 Enterprise Network Infrastructure Design & Implementation

**A Multi-Router Enterprise Network Project Using Cisco Packet Tracer**

## 📌 Project Overview

This project demonstrates the design and configuration of an enterprise network infrastructure using Cisco Packet Tracer.

The network consists of multiple interconnected Cisco routers, switches, PCs, and a centralized server.

The project focuses on implementing routing, switching, network segmentation, security policies, and network services.

## 🛠️ Technologies & Features

### 🔹 Routing
- OSPF Dynamic Routing (Area 0)
- Static Routing
- Default Route Configuration

### 🔹 Switching
- VLAN Configuration (VLAN 10, 20, 30, and 40)
- Inter-VLAN Routing (Router-on-a-Stick)
- IEEE 802.1Q Trunking
- EtherChannel (LACP)
- Spanning Tree Protocol (PVST)

### 🔹 Network Security
- Extended Access Control Lists (ACLs)
- HTTP Traffic Filtering
- ICMP Traffic Restrictions
- SSH Remote Access
- Restricted Management Access

### 🔹 Network Services
- DHCP Configuration for Multiple VLANs
- NAT Overload (PAT)
- Centralized Server Connectivity

## 🌐 VLAN Addressing

| VLAN | Network | Default Gateway |
|---|---|---|
| VLAN 10 | 10.10.10.0/24 | 10.10.10.50 |
| VLAN 20 | 20.20.20.0/24 | 20.20.20.50 |
| VLAN 30 | 30.30.30.0/24 | 30.30.30.50 |
| VLAN 40 | 40.40.40.0/24 | 40.40.40.50 |

## 🎯 Project Objectives

- Design a multi-router enterprise network.
- Implement dynamic routing using OSPF.
- Configure VLANs and inter-VLAN communication.
- Implement EtherChannel using LACP.
- Apply network security policies using ACLs.
- Configure DHCP and NAT services.
- Enable secure remote management using SSH.
